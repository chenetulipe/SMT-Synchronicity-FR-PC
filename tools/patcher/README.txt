==================================================================
           SMT SYNCHRONICITY PROLOGUE - PATCH FRANCAIS
==================================================================

Ce patch applique la traduction francaise complete du jeu :
- Plus de 540 textures et interfaces traduites en francais
- Textes et dialogues francais (polices et accents supportes)
- Menus du lanceur traduits en francais
- Noms des personnages et ennemis traduits
- Discord Rich Presence avec detection de zone et statut

------------------------------------------------------------------
COMMENT L'UTILISER :
------------------------------------------------------------------

1. Double-cliquez sur "lancer_patcher.bat".
   (Une fenetre va s'ouvrir automatiquement dans votre navigateur)

2. Dans la page web :
   - Indiquez le chemin vers le dossier de votre jeu
     (le dossier qui contient synchronicity.exe et le sous-dossier data)
   - Verifiez que les trois voyants sont au vert

3. Cliquez sur le bouton "Appliquer le Patch FR".

4. Une fois termine, lancez "synchronicity.exe" pour jouer !

------------------------------------------------------------------
COMMANDES DU JEU PAR DEFAUT (CLAVIER) :
------------------------------------------------------------------
- ACTION / ATTAQUE (Valider sur l'ecran titre) : Touche X
- SAUT : Touche Z
- MAGIE / COMPETENCE : Touche C
- CHANGER DE PERSONNAGE : Touche V
- PAUSE : Touche Espace
- DIRECTIONS : Fleches du clavier (Haut, Bas, Gauche, Droite)

* Attention sur l'ecran titre : appuyez bien sur la touche X (Action) !
  La touche Entree n'est pas utilisee par le moteur du jeu.

------------------------------------------------------------------
NOTES ET SECURITE :
------------------------------------------------------------------
- Un backup automatique de votre executable (megaten.exe.bak) est
  automatiquement cree avant toute modification.
- Si Python 3 n'est pas installe sur votre ordinateur, telechargez-le
  sur https://www.python.org/downloads/ en pensant a cocher la case
  "Add Python to PATH" lors de l'installation.
