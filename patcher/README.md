## Utilisation Rapide

1. Double-cliquez sur **`lancer_patcher.bat`**.
2. Le navigateur web s'ouvre automatiquement sur l'interface locale (`http://localhost:8765`).
3. Indiquez le dossier de votre jeu (ou directement votre archive `.rar` / `.zip`).
4. Cliquez sur **« Appliquer le Patch FR »** (l'opération prend moins d'une seconde).
5. Lancez `synchronicity.exe` et jouez !

## Architecture 100 % Légale

* Aucun fichier sous droit d'auteur d'Atlus n'est distribué.
* Les modifications d'exécutables et de dialogues sont appliquées sous forme de **diffs binaires (bsdiff)** directement sur votre copie originale.
* Sauvegarde automatique (`megaten.exe.bak`) incluse.
